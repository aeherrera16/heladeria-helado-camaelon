# heladeria-helado-camaelon

Landing + panel editable de accionistas para **Helado Camaleón (KROMA)**.

## Requisitos
- Node.js 18+

## Correr en desarrollo
En dos terminales:

```bash
npm --workspace backend run dev
```

```bash
npm --workspace frontend run dev
```

- Frontend: http://localhost:3000
- Backend: http://localhost:4000

## Build
```bash
npm run build
```
